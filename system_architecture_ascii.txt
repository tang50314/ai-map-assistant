核心业务流程
=============

用户输入旅行需求
        │
        ▼
┌─────────────────────────────────────────────────────────────────────────────────────────────────┐
│  1. 前端接收用户输入 → 发送HTTP请求 → FastAPI网关 → JWT认证 → 路由分发                           │
│  2. 创建旅行规划任务 → 初始化AI团队 → 分配专业代理 → 启动多代理协作                            │
│  3. PreferenceAgent分析用户偏好 → MapToolAgent获取地理信息 → 其他代理并行处理                   │
│  4. 代理间消息传递 → 状态同步 → 结果聚合 → 生成完整旅行方案                                   │
│  5. 结果存储到数据库 → 更新对话历史 → 返回前端展示 → 用户界面更新                             │
└─────────────────────────────────────────────────────────────────────────────────────────────────┘
        │
        ▼
返回个性化旅行方案


系统特色与创新
==============

🚀 智能多代理协作：5个专业代理协同工作，提供全方位旅行规划服务
🔧 企业级稳定性：双重缓存机制、连接池管理、内存泄漏防护
⚡ 高性能架构：异步处理、多级缓存、资源池化、自动扩缩容
🛡️ 安全可靠：JWT认证、CORS防护、输入验证、错误处理
📊 可观测性：全链路监控、性能指标、健康检查、告警机制
🔧 易维护：模块化设计、清晰分层、统一配置、自动化部署


技术栈总结
==========

前端：React + TypeScript + Tailwind CSS + Vite
后端：FastAPI + Python + SQLAlchemy + JWT
AI框架：AutoGen + 多代理系统 + MCP Workbench
数据库：SQLite + 连接池 + ORM
外部服务：百度地图API + DeepSeek大模型 + 硅基流动API
系统管理：内存管理器 + 资源管理器 + 监控告警
